# Athul C Portfolio

A responsive Next.js App Router portfolio built with JavaScript, Tailwind CSS, Framer Motion, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Personalize

Update `data/portfolio.js` with your email address, social profile URLs, resume URL, project links, internship dates, and internship responsibilities. Leave any value empty until you have the correct details; empty links are intentionally disabled.

To use a local resume file, place it in `public/` (for example `public/athul-resume.pdf`) and set `resume` to `/athul-resume.pdf`.

The contact form opens the visitor's email application with a prefilled message; it does not send or store form submissions.

## Production build

```bash
npm run build
npm start
```
